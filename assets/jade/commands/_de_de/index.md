# Jade-Befehle

Die Befehle von Jade: `/jade`-Befehle laufen auf dem Server und brauchen dessen Berechtigung; `/jadec`-Befehle laufen in deinem eigenen Spiel. Gezeigt wird nur, was deine Stufe erlaubt. Öffne dieses Menü mit `/jade`.

*Stufen: 0 alle, 1 Moderatoren, 2 Spielleiter, 3 Admins, 4 Besitzer.*
