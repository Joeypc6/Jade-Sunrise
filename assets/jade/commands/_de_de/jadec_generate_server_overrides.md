# jadec generate_server_overrides

**Verwendung:** `/jadec generate_server_overrides [pattern]`

Schreibt `config/jade/server-plugin-overrides.json` mit deinen aktuellen Optionen (passend zum Muster, falls angegeben), die ein Server seinen Spielern vorgeben kann.
