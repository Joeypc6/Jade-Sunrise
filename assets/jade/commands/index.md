# Jade Commands

The commands Jade adds: `/jade` ones run on the server and need its permission; `/jadec` ones run on your own game. Only what your level allows is listed. Open this menu with `/jade`.

<SubPages />

*Levels: 0 everyone, 1 moderators, 2 game masters, 3 admins, 4 owners.*
