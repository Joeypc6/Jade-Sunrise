# jadec generate_server_overrides

**Uso:** `/jadec generate_server_overrides [pattern]`

Escribe `config/jade/server-plugin-overrides.json` con tus opciones actuales (las que coinciden con el patrón, si lo das), para que un servidor las imponga.
